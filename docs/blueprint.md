# **App Name**: Luật Giao Thông Bot

## Core Features:

- Query Understanding: Interpret user's natural language queries related to traffic laws.
- Document Retrieval: Retrieve relevant articles and clauses from the traffic law database based on the user query.
- Law Summarization: Summarize the retrieved legal information to provide a concise answer to the user's question, and indicate what 'tool's' source articles or clauses were used to compose the answer.
- Display Results: Present the summarized answer, along with references to the source articles/clauses, in a clear and user-friendly interface.
- Feedback Collection: Allow users to provide feedback on the accuracy and usefulness of the answers.

## Style Guidelines:

- Primary color: Deep blue (#3F51B5) to evoke trust and authority, reminiscent of legal documents.
- Background color: Light gray (#F5F5F5) for a clean and professional appearance.
- Accent color: Teal (#008080) to highlight important information and calls to action.
- Body and headline font: 'Inter' sans-serif font, for a clean and modern look that is easy to read on screen.
- Use simple, clear icons to represent different categories of traffic laws.
- Maintain a clean and organized layout for easy navigation and readability.
